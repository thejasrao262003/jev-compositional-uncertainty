\section{Reproducibility}
%======================================================================

Every analysed Jev call used \texttt{jev-1.13.0}. Real-data calls:
Mozilla 2{,}424 (including a label-wording arm) plus a 252-call smoke
test; kernel 2{,}160 plus a 216-call smoke test; Kubernetes 9{,}738
(1{,}082 issues, three nodes, three repeats; the 270-call smoke test's
issues were reused), with model version pinned after 9 smoke calls had
resolved to \texttt{jev-1.14.0}; those calls and one version probe are
kept and excluded. All analysed calls returned HTTP 200 and parsed. The
four comparison models made 3{,}246 deterministic passes each on the
Kubernetes issues, with no failures.
Every dataset, raw response, execution manifest and analysis is
hash-locked in the accompanying repository, as are the pre-registration
documents and their revision history. The figure data in this paper are
generated from committed result files by \texttt{make\_figure\_data.py}.
An audit on 2026-10-23 found one defect: the held-out analysis seeded its
per-tracker bootstrap with Python's salted string hash, so the HR2
one-sided lower bounds varied between runs (0.640--0.644 for the kernel,
0.759--0.763 for Mozilla); point estimates and test outcomes never changed.
The seed is now deterministic (bounds 0.762 and 0.648), and every other
analysis, re-run under a different hash seed, was byte-identical.

\section{Data provenance and release}
%======================================================================

\para{Sources} Bug reports come from the public Mozilla Bugzilla and
Linux kernel Bugzilla, fetched through their REST interfaces. Texts were
cleaned, privacy-scrubbed (names and e-mail addresses removed) and
truncated to 2{,}000 characters; exclusion rules are applied by the
dataset builders and recorded in manifests with SHA-256 hashes.

\para{What is released} Bug identifiers, tracker URLs, reference labels,
text hashes, every model output, every protocol with its commit history,
all analysis code and every result file. Report texts are not
redistributed: the builders regenerate them from the public trackers, and
the hashes verify the regeneration. Bug-tracker links used in the
split-integrity check are released as identifiers only.

\para{What needs access} Re-running model calls needs a TypeSafe API key
for Jev and a GPU for the open models (OpenJev at Hugging Face commit
\texttt{b4a89f5} under vLLM 0.29.0; Qwen2.5, Phi-3.5 and OLMo-2 under
\texttt{transformers}). Every table and figure in this paper can be
regenerated offline from the released outputs, and a script checks every
reported number against the result files.
